# CoreTend — Homebrew tap

```sh
brew install --cask ahmetbsbnr/coretend/coretend
```

Installs [CoreTend](https://github.com/ahmetbsbnr/coretend), a living, local greenhouse for your
Mac, from its notarized GitHub release. macOS 14 or later, Apple silicon.

The cask is maintained in the CoreTend repository (`homebrew/coretend.rb`) and copied here at
each release.
